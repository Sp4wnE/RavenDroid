# Repository privacy

Published documentation uses generic paths and contains no individual workstation or device reports. Local handoffs, historical diagnostics and personal build locations are excluded from the source tree.

Native builds remap development paths to a generic source prefix. Release binaries are checked for the workstation identifiers found during the cleanup, as well as personal home-directory path patterns. Runtime-generated support reports may describe the device running the app; users choose whether to share those reports.

Third-party copyright and license notices are retained. They identify dependency authors and must not be mistaken for personal information about the repository owner. Application localization resources are also retained as functional source files.

The repository remains private and Pages is disabled. GitHub necessarily displays the account that owns the repository; repository cleanup does not make that account anonymous.
